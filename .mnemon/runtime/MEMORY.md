Rain FUI (Flutter FFmpeg GUI at /home/aibeto/code/rain_fui): fluent_ui + fluentui_system_icons only, hand-built shell (no Scaffold, no acrylic/blur), ThemeService persists app_theme and defaults to ThemeMode.system. Surfaces are four layers in AppTheme: page (pure white/black), chrome (bars + docked sidebar), card, inset (terminal, wells), each with chromeFor/cardFor/insetFor/borderFor. 19 plain-Map locale catalogs in lib/i18n (144 keys, en_US fallback, tool/check_i18n.py; French uses U+2019). Layout constants in lib/theme/metrics.dart (gutter 20, contentWidth 960); equal-width option grid; shared picker widths; MiniIconButton is the only small icon button; dropdown popups keep width but no fixed height so Fluent expands to the window and scrolls with a scrollbar past that. Encoding: lib/src/media (86 video / 72 audio encoders, 27 containers, OptionSpec form, per-encoder pix_fmt, rate modes auto/quality/bitrate/CBR, containers filtered by kind and chosen codecs, image sources default to png + image2, typed media extensions replaced), lib/services/job_queue.dart serial queue with SIGSTOP pause and 2000-line log, MediaJobActivity setup page (output name on its own row, destination as grey caption), JobLogActivity terminal view, output to Downloads/rain_fui. Job rows listen to their own job so progress repaints, show state dot, percent, "position / total", and bar colours: green completed, red failed, blue running, pale blue indeterminate, grey queued/paused/cancelled. Light animations only (AnimatedSwitcher 180 ms empty↔list, percent 160 ms, drop overlay 120 ms). Verification: dart analyze + tool/check_ui_rules.py --strict + tool/check_i18n.py + flutter build web; ffmpeg CLI introspection allowed, running the app forbidden. Commits: Chinese Conventional Commits, one per finished item, stamped with that work's real completion time.

Rain FUI（Flutter FFmpeg GUI）：编码页下拉框缺 AVC/HEVC/AV1 有两层原因，都要查。①容器白名单 tool/data/containers-system.json 必须用带 libx264/libx265/libaom/SVT-AV1 的完整构建测量（原生构建量出的 mp4 没有这些 codec id，会把编码器挡在列表外）；②build/ffmpeg/dist/ 只是构建产物，必须跑 scripts/ffmpeg/install-to-app.sh 才会进 linux/ffmpeg、windows/ffmpeg、android/app/src/main/jniLibs、web/ffmpeg；忘了这步时探针仍成功、日志无回退提示，只是列表来自旧二进制。用 tool/check_packaged.py 校验两者 sha256 一致。

Rain FUI 平台层（macOS / web / 版本断言）：macOS 用 scripts/ffmpeg/build-macos.sh —— 每个架构独立 ffbuild/macos-<arch> 与 deps 前缀（build-deps.sh 的 macos-* 用 xcrun clang + -arch/-isysroot/MACOSX_DEPLOYMENT_TARGET 默认 11.0），再 lipo 成 dist/macos/ffmpeg 并 ad-hoc codesign（未签名的 arm64 二进制无法启动）；external-libs.sh 只为 macos 开 videotoolbox/audiotoolbox，vaapi/vpl/mfx/nvenc 只在 linux|windows。install-to-app.sh 把产物放到 macos/ffmpeg/ffmpeg（git 忽略），Xcode Runner 的 "Embed ffmpeg" PBXShellScriptBuildPhase 用 install -m 0755 复制进 Contents/Frameworks 并 ad-hoc 重签名，ffmpeg_locator 已优先查该路径。macOS entitlements 必须去掉 com.apple.security.app-sandbox（沙盒下既不能 exec 内置 helper 也读不到拖入文件），只保留 files.user-selected.read-write + files.downloads.read-write，debug profile 另有 jit/network.server；拖放由 desktop_drop 承担，supportsDropTarget 含 macOS。CI 有独立 build-macos（macos-14）leg，check_expected_encoders.py 用 CONFIG_DIRS['macos']='macos-arm64' 读 configure 结果。web 端暂时废弃：build.sh / install-to-app.sh / ci.yml matrix / check_packaged.py 的入口都注释掉了，代码一行未删，build-web.sh 需 RAIN_FUI_ALLOW_WEB_BUILD=1 才执行，因此 flutter build web 已不在验证清单里。版本断言接受 RELEASE 的 tag、n 前缀或 git 短提交号三者之一（CI 的 submodule 没有 tag，FFmpeg 只打印纯提交号）。iOS 不支持：iOS 禁止 spawn 子进程，与整套「exec 内置 ffmpeg」后端冲突（用户本轮选择先只做 macOS）。
